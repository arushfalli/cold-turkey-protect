Stop Cold Turkey from being removed.

One moment of weakness is all it takes. This free tool permanently blocks the Cold Turkey Removal Tool and uninstaller — so you can actually stick to your goals.

Download — Free
Windows 10 & 11 · No install required · Open source

How it works

1
Download and double-click UITVOEREN.bat
2
Click Yes on the Windows admin prompt
3
Done. Cold Turkey is now protected.

Questions

Does Cold Turkey still work after this?

Yes. Blocking, schedules, and settings all work normally. Only removal is blocked.

What if I download a new Removal Tool?

Run this tool again — it will find and block any new Removal Tools in your Downloads or Desktop folder.

Can I undo this?

Yes, but it requires deliberate steps in an admin command prompt. There's no one-click undo — that's the point.

Does this work with Cold Turkey Pro?

Yes.

Is this safe? What does it actually do?

It sets Windows file permissions (DENY) on Cold Turkey's uninstaller and installation folder. No background processes, no network access, fully open source.
